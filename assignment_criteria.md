## Task

Each group identifies a **real-world problem** that can be effectively solved through **NLP methods**. The group must:

1. Propose a solution.
2. Develop a project including **theoretical** and **empirical** analyses.
3. Demonstrate the advantages of the proposed solution.

## Suggested Report Structure

1. **Cover page** — project title and team members' information
2. **Abstract**
3. **Introduction** — studied problem and aim of project
4. **Background** — challenges behind the problem
5. **Methodology** — theoretical analysis of the proposed solution
6. **Experiment Results** — implementation, workflow/algorithm, GitHub/Colab link, data, results
7. **Conclusion**
8. **Team Member Contribution** — what each member contributed
9. **References** — any style (e.g., APA)

---

## Report Content Requirements (40 marks)

The report must include:

- **Introduction** to the proposed real-world problem — explain the impact, real-world implications, challenges, and benefits of solving it.
- **Theoretical justifications** for the proposed NLP method — explain why the method addresses the problem.
- **Workflow of the developed code** — pre-processing, algorithmic details, and experiment results. Include empirical analysis on sample data (real-world or synthetic).
  - Use a **small model** with a **small dataset** so it runs on free Colab tier.
  - Place original code in a **public GitHub repository**; include the URL in the report.
  - Report should only include the **workflow**, not the full code.
